# Bounded member-bearing consumer accounting

The isolated module `anymesher._prepared_member_accounting` consumes the additive
ANYgeometry `PreparedMemberSheetJointComponent` contract. It is not connected
to production dispatch, the existing current-only receipt or application defaults.

`query_prepared_member_accounting(model, joint_edge_id)` obtains and revalidates
the member-bearing owner receipt, complete authored constraint inventory and live
polynomial ancestry. Optional supplied receipts are untrusted: their contents are
structurally pinned before callback-bearing work and rederived against the live owner.
`validate_prepared_member_accounting` rederives the complete accounting result.

The finite scope is the owner's complete two-Plane/Straight-Sheet document with
one original full-range straight boundary Member and one exact vertex-on-edge
point Attachment, in either member orientation. Original/current typed records
are compared exhaustively. Ordered member-use traversal retains orientation,
parent ranges and ancestor intervals. The point carrier/station is retained as
exact fractions; generated Sheet-joint attachment and membership records remain
explicit. Required source-carrier ancestry must be available and have zero
restriction error. No linear station formula is applied to nonlinear branch
curves. Generated joint edges do not acquire invented source ancestry.

Unexpected typed records, additional isolated vertices, source tags and opaque
reference categories refuse. The only allowed current tags describe owner-recorded
intersection decomposition seams. Full owner records and the complete inventory
remain in the result; accounting does not authorize their arbitrary semantics.
Wrong-model, stale, forged-omission, same-revision and callback-mutation inputs
refuse. Final owner validations are callback-free. No digest substitutes for
content rederivation.

Evidence capture accepts exact builtin immutable scalar/container types, UUIDs
and actual owner dataclasses. It walks stored dataclass fields into a separate
immutable value tree; it never invokes `deepcopy`, receipt equality or custom
copy hooks. Original optional receipts are validated without callbacks before
user actions, then compared with the pre-hook content snapshot after reproof.
Accounting validation applies the same guard before inspecting schema values.
Scalar subclasses and mutable/unrecognized evidence containers explicitly refuse.
Alias-returning copy hooks never execute.

Class checks use identity comparisons against a closed tuple of the actual
owner receipt/definition classes. No attributes, equality or hashing of unknown
classes are inspected, so custom metaclasses cannot run during capture. Cyclic
graphs and nesting beyond 64 levels refuse with `MeshError`; this bounds malformed
evidence nesting, not tuple breadth or ordinary model/entity counts.

Optional receipt contents are pinned before geometry serialization, which can
itself invoke source metadata copy hooks. A source-side hook cannot repair
original evidence before capture. Generated result contents are separately pinned
immediately after derivation and checked after the closing owner validations and
final geometry serialization, including when no optional receipts were supplied.

The root's original repair-on-copy counterexample and log are retained in
`ANYgeometry/reports/member-component-7b278fa/consumer_copy_hook_probe.py` and
`consumer-copy-hook-probe.log`. It demonstrated a real bypass in the first
consumer candidate; the earlier 16 passing checks did not establish copy-hook
safety. The new focused regressions cover all three optional receipt types,
both query/validation paths and accounting scalar equality/copy hooks. They also
confirm typed refusal of malformed/duplicate relation payloads through the actual
7b owner validator, without duplicating owner geometry classification. Synthetic
opaque/scope/ancestry/isolated-vertex checks exercise consumer refusal branches
without claiming forged owner data is admissible.

The result explicitly grants no beam discretization, external reference transfer,
solver admission or publication authority. It has no candidate mesh and proves
no nodes, elements, stations in a mesh, quadratic sharing or coupling records.
