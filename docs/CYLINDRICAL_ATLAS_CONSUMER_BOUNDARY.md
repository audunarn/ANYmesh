# Cylindrical atlas consumer boundary

This is the first owner/chart integration increment, not cylindrical mesh
activation. The public planar-only guard and generation defaults remain unchanged.

Owner authority is ANYgeometry source
`e11037269d2a18a53058c3ff55964af82f7f4ef8`, with private atlas wheel SHA-256
`DBBDCCF292E3269B82BEECFB8754CE5974E84E16D6FF8630FD5FAC1DCB8635F8`.
It differs from the trim-only `12683ae`/`EA0C3A60...` artifact despite their shared
0.4.3 version label. This does not silently replace the earlier private consumer
wheel dependency lock or qualify an installed atlas/mesher pair.

`_cylindrical_atlas.prepare_cylindrical_atlas` consumes the owner's qualified
selection and reference-bound result and prepares one physical metric chart per
actual selected FaceUse. Source Faces remain distinct. Ordered source occurrence
requests and returned samples, uncertainty enclosures, native Edge parameters,
canonical identity keys, void exclusions and external radial incidence remain
owner data. No downstream geometry proof, coordinate welding, virtual seam,
partial-edge clipping, model mutation or mesh-node allocation is introduced.

Fresh evaluation and explicit validation delegate to owner binding checks.
Operational and cancellation exceptions propagate without relabeling; an
unqualified atlas cannot produce a partial adapter. Physical charts also enforce
their existing model/revision binding and same-support parameterization restriction.

Focused source tests exercise real publicly authored eight-sector rings and a
two-notch seam-crossing hole, reference changes, exact shared keys, physical chart
lengths, caller-binding tampering, stale geometry, cancellation and owner budget
refusal. They do not establish triangulation/refinement, shared mesh-node
allocation, lifted mesh quality, quadratic seams, installed-wheel compatibility,
performance or public activation. Those remain subsequent accepted-plan gates.
