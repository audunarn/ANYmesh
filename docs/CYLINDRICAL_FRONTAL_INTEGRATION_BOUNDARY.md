# Cylindrical Frontal-Delaunay integration boundary

The accepted atlas consumer feeds the existing private native-face implementation
through an internal binding parameter. Public cylindrical activation remains
closed until refinement, identity, physical quality and consumer gates pass.

- Only a qualified, complete owner atlas for the exact working UUID/revision is
  admitted. One selected FaceUse must own the requested face.
- Chart coordinates are circumferential arc length and axial distance. Spatial
  fields receive physical owner evaluation and position-dependent derivatives.
- Existing edge registries, protected coordinates, surface qualification,
  optimizer, recombination, lifting and merge remain authoritative.
- Legacy cylindrical lattice, planar, mapped and automatic defaults are unchanged.
- The focused test injects the binding at the private seam. It is not evidence
  that public cylindrical activation or the complete 0.5.0 release is qualified.

Still required: partial-patch owner contract, trimmed/intersected work-bearing
fixtures, periodic incidence/normal checks, quadratic and recombination variants,
cancellation/failed-publication tests, backend parity, physical quality comparison,
10k/100k performance and memory, installed-wheel/platform and normal CI gates.
No release or downstream production change is authorized by this integration.
